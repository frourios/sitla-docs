# Byte-format and conformance reference

`codec.ts` provides the SITLA v0.2 restricted canonical JSON codec, root derivation, fixed DID-document reconstruction, Gregorian time checks, static record semantics and replacement-chain checks. The root descriptor remains version 1; updating the protocol does not itself change a root DID. The reference code and `tests/` are **Apache-2.0**; see [the license](LICENSE) and the separate [specification patent grant](../PATENTS.md). Specifications, schemas and public vectors remain CC0-1.0. Existing application code is not relicensed.

The parser checks a 65,536-byte input limit and 32 container levels before JSON parsing; canonicalization also limits traversal to 10,000 nodes and the same byte/depth budget. Duplicate fields and alternate spellings are rejected by exact canonical-wire comparison. `parseTime` validates real calendar dates and UTC encoding. These concrete reference limits are not a universal deployment resource policy. A caller must enforce advertised budgets, deadlines, request rates and isolation; no wall-clock interruption, process sandbox, network policy, live status lookup, trust-anchor selection, clock assurance or replay store is implemented here.

`validateSemantics` requires prior JSON Schema validation. It is a static helper, not a complete authenticated service or cryptographic policy engine. `conformance.ts` validates fixed schemas/vectors with Ajv and Node crypto. Its fixture verification-key map is trusted test input, never an operator-discovery or issuer-trust mechanism. Runtime clients must validate authorization scopes, key histories, current epochs/status, signature suites, content/amount/terms digests and user permissions independently before an effect.

The files use erasable TypeScript. Node.js 26 can import `codec.ts` directly without compilation or separate declaration files. From this repository, `node --input-type=module -e 'import { canonical } from "./reference/codec.ts"; console.log(canonical({ version: 1 }))'` works without the application repository. Install the locked development dependencies with `npm ci --ignore-scripts` before running `npm test`. The independent Python test uses `dilithium-py`, `jsonschema` and `cryptography` and imports no TypeScript code. Dependency versions are pinned in `tests/requirements.txt`. No private signing key is distributed.
